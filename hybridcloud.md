# Hybrid Cloud

Eine Hybrid Cloud kombiniert Public Cloud und Private Cloud (oder On-Premise), sodass ein Unternehmen je nach Anwendung selbst entscheiden kann, wo die Daten liegen. So können zum Beispiel sensible Daten On-Premise bleiben, während andere Anwendungen flexibel in der Public Cloud laufen.

Weiterführender Link: https://azure.microsoft.com/de-de/resources/cloud-computing-dictionary/what-is-hybrid-cloud
