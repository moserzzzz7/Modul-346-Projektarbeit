# Public Cloud

In der Public Cloud teilen sich viele verschiedene Kunden dieselbe Infrastruktur eines Anbieters wie Microsoft Azure oder AWS, wobei die Daten der Kunden logisch voneinander getrennt bleiben. Das ist meist günstiger und flexibler, weil man nur die Ressourcen bezahlt, die man wirklich braucht.

Weiterführender Link: https://azure.microsoft.com/de-de/resources/cloud-computing-dictionary/what-is-a-public-cloud
