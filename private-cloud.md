# Private Cloud

Bei einer Private Cloud steht die Cloud-Infrastruktur nur einem einzigen Unternehmen zur Verfügung, entweder im eigenen Rechenzentrum oder exklusiv bei einem Anbieter gehostet. Das bietet mehr Kontrolle und Sicherheit als eine Public Cloud, ist dafür aber meist teurer.

Weiterführender Link: https://azure.microsoft.com/de-de/resources/cloud-computing-dictionary/what-is-a-private-cloud
