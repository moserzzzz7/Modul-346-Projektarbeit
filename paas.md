# PaaS (Platform as a Service)

Bei PaaS bekommt man vom Anbieter bereits eine fertige Plattform mit Betriebssystem und Laufzeitumgebung, auf der man direkt eigene Anwendungen entwickeln kann. Um die Infrastruktur, Updates oder Server dahinter muss man sich dabei nicht mehr kümmern.

Weiterführender Link: https://azure.microsoft.com/de-de/resources/cloud-computing-dictionary/what-is-paas
